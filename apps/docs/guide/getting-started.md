# Getting started

## Install

```bash
pnpm add @gk-ui/core @gk-ui/tokens
```

## Use

```js
import "@gk-ui/tokens/tokens.css";
import "@gk-ui/core";
```

```html
<gk-button variant="primary">Continue</gk-button>
```
