# 快速開始

## 安裝

```bash
pnpm add @gk-ui/core @gk-ui/tokens
```

## 使用方式

```js
import "@gk-ui/tokens/tokens.css";
import "@gk-ui/core";
```

```html
<gk-button variant="primary">繼續</gk-button>
```
