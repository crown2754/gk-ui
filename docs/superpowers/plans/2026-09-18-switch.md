# Switch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `gk-switch` with Button-aligned size enum, brand ON/OFF chrome, CustomEvent `change`, and EN + zh-TW docs under Data Entry.

**Architecture:** Single Lit element under `packages/core/src/switch/`. Shadow hosts a `<button type="button" role="switch">` (track + thumb) plus an optional label slot. No native checkbox.

**Tech Stack:** Lit 3, Vitest + `@open-wc/testing`, VitePress, pnpm `@gk-ui/core`.

## Global Constraints

- Props: `checked` false, `size` sm\|md\|lg default md, `disabled` false, `round` true.
- Event: bubbling composed `change` with `detail: { checked: boolean }` only (no native leak).
- Track: sm 28×16 / md 36×20 / lg 44×24; thumb 12 / 16 / 20.
- Disabled opacity **0.4** (not 0.5).
- Sidebar Data Entry / 資料輸入: Date Picker, Input, Switch.
- Tests: `corepack pnpm --filter @gk-ui/core test`
- Docs: `corepack pnpm docs:build`
