# Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `gk-card` with cover (URL + slot), header/content/footer, hoverable, bordered, segmented, closable → `gk-close`, plus EN/zh-TW docs.

**Architecture:** Single Lit element under `packages/core/src/card/`, mirroring avatar/button. Slot presence detected via `@slotchange` for header/cover so title attr and cover URL only render when slots are empty.

**Tech Stack:** Lit 3, Vitest + `@open-wc/testing`, VitePress, pnpm `@gk-ui/core`.

## Global Constraints

- Cover: `#cover` slot wins over `cover` URL attribute.
- Closable: emit bubbling composed `gk-close` only; do not hide/remove the card.
- `bordered` default `true`; `segmented` / `hoverable` / `closable` default `false`.
- Size: `sm` \| `md` \| `lg`, default `md`.
- Sidebar alphabetical: Avatar → Button → **Card**.
- No collapse, loading, CardGroup.
- Tests: `corepack pnpm --filter @gk-ui/core test`
- Docs: `corepack pnpm docs:build`
- Commit after each task; do not push unless asked.

- [ ] **Step 4: Implement element**

Create `packages/core/src/card/gk-card.ts`:

```ts
import { LitElement, html, nothing } from "lit";
import { customElement, property, state } from "lit/decorators.js";
import { cardStyles } from "./gk-card.styles.js";

export type GkCardSize = "sm" | "md" | "lg";

@customElement("gk-card")
export class GkCard extends LitElement {
  static styles = cardStyles;

  @property({ reflect: true })
  title = "";

  @property({ reflect: true })
  size: GkCardSize = "md";

  @property({ reflect: true })
  cover?: string;

  @property({ type: Boolean, reflect: true })
  hoverable = false;

  @property({ type: Boolean, reflect: true })
  bordered = true;

  @property({ type: Boolean, reflect: true })
  segmented = false;

  @property({ type: Boolean, reflect: true })
  closable = false;

  @state()
  private hasCoverSlot = false;

  @state()
  private hasHeaderSlot = false;

  private onCoverSlotChange = (e: Event) => {
    const slot = e.target as HTMLSlotElement;
    this.hasCoverSlot = slot.assignedNodes({ flatten: true }).length > 0;
  };

  private onHeaderSlotChange = (e: Event) => {
    const slot = e.target as HTMLSlotElement;
    this.hasHeaderSlot = slot.assignedNodes({ flatten: true }).length > 0;
  };

  private onClose = () => {
    this.dispatchEvent(
      new CustomEvent("gk-close", { bubbles: true, composed: true }),
    );
  };

  private get showBuiltInCover() {
    return Boolean(this.cover) && !this.hasCoverSlot;
  }

  private get showHeader() {
    return this.hasHeaderSlot || Boolean(this.title) || this.closable;
  }

  render() {
    return html`
      <article part="base">
        <div part="cover" ?hidden=${!this.showBuiltInCover && !this.hasCoverSlot}>
          ${this.showBuiltInCover
            ? html`<img part="cover" src=${this.cover!} alt="" />`
            : nothing}
          <slot name="cover" @slotchange=${this.onCoverSlotChange}></slot>
        </div>
        ${this.showHeader
          ? html`
              <header part="header">
                <div class="gk-card__header-main">
                  ${this.hasHeaderSlot
                    ? nothing
                    : this.title
                      ? html`<div class="gk-card__title">${this.title}</div>`
                      : nothing}
                  <slot name="header" @slotchange=${this.onHeaderSlotChange}></slot>
                </div>
                <div part="action">
                  <slot name="action"></slot>
                  ${this.closable
                    ? html`<button
                        type="button"
                        part="close"
                        aria-label="Close"
                        @click=${this.onClose}
                      >
                        ×
                      </button>`
                    : nothing}
                </div>
              </header>
            `
          : html`<slot name="header" @slotchange=${this.onHeaderSlotChange} hidden></slot>`}
        <div part="content"><slot></slot></div>
        <footer part="footer">
          <slot name="footer"></slot>
        </footer>
      </article>
    `;
  }
}

declare global {
  interface HTMLElementTagNameMap {
    "gk-card": GkCard;
  }
}
```

Fix part collision: do **not** put `part="cover"` on both wrapper and img. Prefer:

- Wrapper: `class="gk-card__cover"` or `part="cover"` on wrapper only  
- Img: `part="cover-image"` **or** img without part and wrapper is `part="cover"`

Update the test accordingly: query `img` inside `[part=cover]` or use `img` with `part="cover-image"` and change the test to:

```ts
el.shadowRoot?.querySelector("[part='cover'] img")
// or
el.shadowRoot?.querySelector("img[part='cover-image']")
```

Align styles + tests to one approach: **wrapper `part="cover"`, img has no part** (or `cover-image`). Spec lists `cover` as a part — wrapper is enough.

Hide empty footer when footer slot empty (optional `@slotchange` + `hidden` on footer) to avoid extra padding — recommended for polish.

Note: Lit reserves `title` on HTMLElement — using `@property() title` overrides the native title tooltip. Prefer renaming reflected attribute if conflicts appear in tests; if native `title` tooltip becomes an issue, use `cardTitle` with `attribute: 'title'`. Prefer:

```ts
@property({ reflect: true })
override title = "";
```

Or keep as-is matching Naive/`title` attr — document that it also sets the HTML title tooltip. Spec says `title` attribute — implement as specified.
